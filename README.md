# Стальной кочевник — плейтест

Играть: **https://babazazu-game.github.io/steel-nomad-play/**

Это собранная тестовая версия игры, а не её исходники.

Магазин работает как в настоящей версии: часть обликов и водителей
открывается за просмотр рекламы (здесь реклама засчитывается сразу), часть
выпадает из сундуков на форпостах, а платные предметы в тестовой версии
купить нельзя.

Прогресс сохраняется в браузере, на том устройстве, где вы играете.
Начать заново как новый игрок: добавьте к ссылке `?reset=1`.
