# Стальной кочевник — плейтест

Играть: **https://babazazu-game.github.io/steel-nomad-play/**

Это собранная тестовая версия игры, а не её исходники. В ней открыты все
облики конвоя и все водители — платить на обычной веб-странице нечем, а
магазин как раз одна из вещей, которые мы просим посмотреть.

Прогресс сохраняется в браузере, на том устройстве, где вы играете.

Всё остальное — бой, дороги и все числа — такое же, как в настоящей версии:
иначе замеры отвечали бы не на тот вопрос.
